# Waymark — agent notes

Waymark is an Expo SDK 57 / React Native 0.86 (New Architecture) trip planner for
iOS, Android and web, backed by Supabase. See `docs/` for architecture, security
and design decisions, and `README.md` for status.

## Secrets — ABSOLUTE RULES (never violate)

- **NEVER read, print, echo, cat, grep, `env`, `printenv`, `export -p`, `git show`,
  `git diff`, or otherwise display the contents of any env or secret file.**
  This includes `.env`, `.env.*`, `*.env`, and anything matching `*secret*`,
  `*credential*`, `*.key`, `*.pem`. Do not preview, pipe, log or summarize them.
- **NEVER write to or overwrite an existing `.env`.** Creating one with `>`/`cat >`
  destroys the user's config (it happened once in this repo and was unrecoverable).
  If a file may exist, check `[ -f .env ]` and STOP; ask the user to create/own it.
- **NEVER copy a secret's value anywhere.** Reference `EXPO_PUBLIC_SUPABASE_URL` /
  `EXPO_PUBLIC_SUPABASE_ANON_KEY` by name only.
- To regenerate a `.env`, the user copies `.env.example` and fills it — agent does
  not. `supabase start` prints the local API URL + anon key; let the user paste them.

## Running the app

The app uses native modules Expo Go does not ship (`lottie-react-native`). It must
run as a **development build**, not Expo Go:

```
cp .env.example .env     # user fills in Supabase URL + anon key
pnpm start:dev-client    # Metro for the installed dev client
pnpm android             # expo run:android: prebuild + build + install
pnpm ios                 # expo run:ios
```

- `android/` and `ios/` are generated by prebuild and gitignored — never commit them.
- The dev build embeds `EXPO_PUBLIC_*` at bundle time. With no `.env`, the app throws
  "Missing Supabase configuration" and shows a blank screen; that is not a UI bug.

## Quality gates (must pass before a change is done)

```
pnpm typecheck
pnpm lint        # 0 errors; a few react-hook-form "Compilation Skipped" warnings are pre-existing
pnpm test        # Vitest, pure logic
supabase test db # pgTAP RLS + RPC tests (requires the Supabase CLI + Docker)
```

## Conventions

- Visual values only through `@/theme` tokens; no raw hex/font values in feature code.
- Copy renders through `AppText` roles.
- Data goes through feature hooks (TanStack Query), never direct Supabase calls in screens.
- Don't loosen RLS. Privileged writes go through security-definer RPCs.
- The Airmail design spec is `design_handoff_airmail_v3/README.md`; the visual system
  is documented in `docs/DESIGN_DECISIONS.md`.
